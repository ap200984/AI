# Инструкции проекта

## Технологический стек

- Язык программирования: Python 3.12.
- Пакетный менеджер: UV.
- Форматтер и линтер: Ruff.
- Фреймворк: FastAPI.
- HTTP-клиент: httpx.AsyncClient.

## Правила разработки

- Используй асинхронные HTTP-запросы.
- Используй Pydantic для валидации параметров.
- Используй UV для управления зависимостями.
- Не храни пароли и токены в исходном коде.

## Проверка кода

После каждого изменения кода обязательно выполни:

    uv run ruff format
    uv run ruff check

Исправь все обнаруженные ошибки и предупреждения.

## Ограничения

- Не изменяй файлы за пределами проекта.
- Не изменяй файл с инструкциями.
- Не выполняй git push без разрешения пользователя.
